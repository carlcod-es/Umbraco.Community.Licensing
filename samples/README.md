# Acme Contact Form sample

This folder holds a demo site for the fictional Acme Contact Form product. It is never published.

## Prerequisites

- .NET 10 SDK
- Node 24.13 or newer

## First run

1. Copy `Acme.ContactForm.Site/appsettings.Local.example.json` to `Acme.ContactForm.Site/appsettings.Local.json`.
2. In the copy, set an administrator email and password. Use a password of your own.
3. From the repo root, run:

   ```
   node samples/run-demo.mjs
   ```

The command does this:

- Runs `npm ci` in `Acme.ContactForm/Client` if `node_modules` is missing.
- Runs `npm run build` if the client bundle is missing or older than the client sources.
- Runs `dotnet run --project samples/Acme.ContactForm.Site`.

When the site is up, browse to <http://localhost:15329> and log in at <http://localhost:15329/umbraco> with the email and password from step 2. The first start installs Umbraco, so it takes a little longer.

## Notes

- `Acme.ContactForm.Site/appsettings.json` holds demo values generated by the Umbraco template (`Umbraco:CMS:Imaging:HMACSecretKey` and `Umbraco:CMS:Global:Id`). Never reuse them in a real site.
- `appsettings.Local.json` is only loaded in Debug builds (`#if DEBUG` in the site's `Program.cs`). `dotnet run` builds Debug by default, so the start command above picks it up. Do not pass `-c Release`.
